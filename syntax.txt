
Особенности Kotlin

В отличие от Scala 3, Kotlin сохранил классические фигурные скобки { }, но избавился от точек с запятой ; и предлагает невероятно лаконичный и безопасный код.
Kotlin — это современный язык от компании JetBrains. Он полностью совместим с Java, но убирает её многословность. Главный упор сделан на безопасность (защиту от null) и читаемость.

1. Переменные: изменяемые и неизменяемые

Тип данных указывать необязательно, Kotlin выводит его автоматически.
- val — константа (read-only). Значение нельзя изменить после присвоения.
- var — обычная переменная (mutable). Значение можно менять.

val name = "Иван"  // Константа. Перезаписать name = "Петр" нельзя.
var age = 25       // Переменная. Можно сделать age = 26.

2. Структура кода (с фигурными скобками)

// В Kotlin блоки кода всегда выделяются фигурными скобками { }. Круглые скобки в условиях обязательны.
if (age >= 18) {
    println("Доступ разрешен")
} else {
    println("Доступ запрещен")
}

3. When (аналог switch / match)

// В Kotlin вместо match используется ключевое слово when. Оно может возвращать значение как выражение.
val day = 1
val dayName = when (day) {
    1 -> "Monday"
    2 -> "Tuesday"
    else -> "Unknown" // 'else' обязателен, если перебраны не все варианты
}

4. Функции (методы)

Функции создаются с помощью ключевого слова fun. Если функция состоит из одного выражения, её можно записать через знак =. Слово return для коротких функций не требуется.
// Обычная функция
fun sum(x: Int, y: Int): Int {
    return x + y
}

// Краткая запись (функция-выражение)
fun sumShort(x: Int, y: Int) = x + y
val result = sumShort(5, 10) // result равен 15

5. Lambda (анонимная функция)

// Лямбды в Kotlin пишутся внутри фигурных скобок { }. Если аргумент у лямбды один, его можно не объявлять, а использовать встроенное имя it.
val add = { a: Int, b: Int -> a + b }

// Использование:
List(3) { it + 1 }.map { x -> x * 2 }

// Краткая запись через 'it':
val list = listOf(1, 2, 3)
val doubled = list.map { it * 2 }

6. Создание объектов и классов

// Конструктор пишется прямо в круглых скобках после имени класса. Ключевое слово new для создания объекта не используется.
class Car(val brand: String, var speed: Int) {
    fun drive() {
        println("Машина $brand едет со скоростью $speed км/ч")
    }
}

// Создаем машину
val myCar = Car("Toyota", 90)
myCar.drive() // Выведет: Машина Toyota едет со скоростью 90 км/ч

7. Коллекции и операции над ними

// По умолчанию все стандартные коллекции в Kotlin разделены на неизменяемые (read-only) и изменяемые (mutable).
val numbers = listOf(1, 2, 3) // Неизменяемый список
numbers.map { it * 2 }
numbers.filter { it > 1 }
numbers.forEach { println(it) }

8. Циклы

Для циклов используется оператор in. Ключевое слово yield для генерации коллекций «на лету» в стандартном цикле Kotlin отсутствует (для этого используются Sequences).

val numbers = listOf(1, 2, 3)
for (n in numbers) {
    println(n)
}
// Диапазоны (от 1 до 5 включительно)
for (i in 1..5) {
    println(i)
}

9. Data class (аналог Case class в Scala)

// Идеально подходит для моделей данных и DTO. Автоматически создает методы toString(), equals(), hashCode() и copy().
data class User(
    val id: Long,
    val name: String
)
// Создание:
val user = User(1, "Alex")

10. Enum

// Перечисления объявляются с помощью комбинации ключевых слов enum class.
enum class Status {
    ACTIVE, BLOCKED, DELETED
}
// Использование:
val status = Status.ACTIVE

11. Interfaces (аналог Traits)

// Интерфейсы в Kotlin могут содержать как объявления методов, так и их дефолтную реализацию.
interface Animal {
    fun sound(): String
    fun sleep() = "Zzz" // Дефолтная реализация
}

// Реализация (вместо extends/implements используется двоеточие)
class Dog : Animal {
    override fun sound() = "Woof"
}

12. Object (Singleton)

// Ключевое слово object используется для объявления класса, который существует в единственном экземпляре (паттерн Одиночка). Это прямой аналог статических методов.
object Utils {
    fun hello() {
        println("Hello")
    }
}
// Вызов:
Utils.hello()

13. Extension Functions (Методы расширения)

// Kotlin позволяет добавлять новые функции в существующие классы без их наследования. Пишется как ИмяКласса.имяФункции.
fun String.shout(): String {
    return this.uppercase()
}
// Использование:
println("hello".shout()) // Выведет: HELLO

14. Null Safety (Вместо Option / null)

// В Kotlin безопасность от null встроена на уровне типов данных. Знак ? означает, что переменная может быть null. Для безопасного вызова используется ?., а вместо getOrElse — оператор «Элвис» ?:.
val name: String? = "Alex"

// Безопасный вызов (вызовется, только если name не null)
println(name?.length) 
// Получение значения или дефолтный вариант (Элвис-оператор)
val resultName = name ?: "Unknown"
// Проверка через when (аналог pattern matching)
when (name) {
    null -> println("Empty")
    else -> println(name)
}

15. Основные коллекции

listOf(1, 2, 3)             // Неизменяемый список (List)
mutableListOf(1, 2, 3)      // Изменяемый список (можно делать .add())
setOf(1, 2, 3)              // Множество unique элементов (Set)
mapOf("a" to 1, "b" to 2)   // Словарь (Map)
